> **Примітка:** Цей проект в активній розробці (Work in Progress). 

Цей проект це перероблена версія мого старого проекту написаного на Python з використанням PyQt5
Я був незадоволений швидкістю та складністю розгортування самого перекладача. Тому я вирішив повністю його переписати на мові програмування С
використовуючі низькорівневу бібліотеку для відображення, щоб навчитися та дізнатися які є плюси використовувати низькорівневу розробку.
Головною ціллю є адаптація мого минулого проекту в нове, швидке, й легко розгортуванне середовище - без використання високорівневих інструментів як GTK або QT.

## 🚀 Можливості зараз

На даному етапі реалізовано базову взаємодію з дисплейним сервером та рендеринг:
* Підключення до Wayland композитора (`wl_display_connect`).
* Ініціалізація та обробка глобальний об'єктів для вхідної переферії, та рендеру інтерфейсу
* Створення вікна за допомогою розширення `xdg_shell`.
* Відмальовування зоображення у вигляді 1D массиву як інтерфейс
